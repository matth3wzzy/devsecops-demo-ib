# 🛡️ DevSecOps CI/CD Security Pipeline

## Проект для Всероссийской олимпиады школьников по информатике
### Профиль: "Информационная безопасность"

## 📋 Описание проекта
Автоматизированный CI/CD пайплайн для проверки безопасности исходного кода. 
Проект демонстрирует интеграцию SAST-инструментов (Bandit, Semgrep) в процесс разработки.

## 🎯 Цели проекта
1. Автоматическое обнаружение уязвимостей в коде
2. Интеграция проверок безопасности в процесс CI/CD
3. Блокировка опасного кода через проверку Pull Requests
4. Создание готового к использованию решения для малых команд

## 🔧 Технологии
- **GitHub Actions** - система непрерывной интеграции
- **Bandit** - статический анализатор кода для Python
- **Semgrep** - универсальный статический анализатор
- **Python 3.10** - язык реализации демо-кода

## 🚀 Как работает
1. При каждом push или Pull Request автоматически запускается пайплайн
2. Устанавливаются инструменты безопасности (Bandit, Semgrep)
3. Проверяется весь Python код в папке `src/`
4. При обнаружении уязвимостей создаются отчеты
5. Отчеты сохраняются как артефакты workflow

- ✅ Обнаружены Command Injection уязвимости
- ✅ Найдены hardcoded secrets (пароли в коде)
- ✅ Пайплайн успешно блокирует опасные изменения
