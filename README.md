### 📋 Описание
Демонстрационный проект, показывающий интеграцию статического анализа кода (SAST) в процесс непрерывной интеграции (CI/CD).

### 🎯 Цель
Создать автоматизированный пайплайн безопасности, который:
- Автоматически проверяет код на уязвимости
- Блокирует слияние опасного кода
- Уведомляет разработчиков о проблемах
